shub

A private home server

shub is a home server that Chris Cotter runs for personal use. It isn't a public service, and only its owner can use it.

shub connects to Google with read-only access to its owner's Gmail and Google Calendar accounts. Scheduled jobs use that access to summarize the owner's own mail and upcoming events.

For details about what shub reads and how it handles that data, see the shub privacy policy.
