shub privacy policy

Effective November 13, 2026

shub is a private home server that Chris Cotter runs for personal use. This policy describes how shub handles data from Google accounts.

Whose data shub accesses

shub accesses only Google accounts that belong to its owner. Nobody else can connect an account to shub.

What shub reads

shub requests the following read-only Google permissions:

  • Gmail (gmail.readonly): read and search email messages, threads, and labels.
  • Google Calendar (calendar.readonly): read calendars and events.

shub can't send, change, or delete email, and it can't create, change, or delete calendar events.

How shub uses the data

Scheduled jobs on shub read recent mail and upcoming events to produce summaries for the owner, such as a daily digest. To write those summaries, shub sends the relevant message and event content to Anthropic's Claude API. shub uses the data for no other purpose.

Where the data is stored

Summaries are saved on shub, a server in the owner's home that only the owner can access. Access tokens for the Google accounts are stored on shub and in encrypted backups that only the owner can decrypt.

Sharing

shub doesn't sell, share, or transfer Google user data to anyone, except to Anthropic's Claude API as described in the preceding section. shub doesn't use Google user data for advertising.

shub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Remove access

To revoke shub's access to a Google account, remove "shub-gmail" on the Third-party apps and services page of that Google account.
